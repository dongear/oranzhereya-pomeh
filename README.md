# Цветочный магазин «Помеха»

Сайт, где из звука вырастает растение. Учебный проект по креативному проектированию, вдохновлённый музыкой Xiu Xiu: красиво, нежно и немного тревожно.

## Что можно делать

- Посадить звук: загрузить mp3/wav или записать с микрофона.
- Смотреть, как растёт растение: грязная пиксельная био-органика в духе Гигера: плоть, позвонки, когти, коконы и рты, собранные из чёрно-белого пиксельного шума. Их форма, число и мутации зависят от громкости, высоты тона, шумности, низких частот и резких всплесков.
- Подкормить растение другим звуком: оно перерастёт, может мутировать или переродиться.
- Послушать, как растение поёт, покрутить ручки голоса (скорость, яркость, эхо, простор, дрожь, плавание) и сохранить голос в WAV.
- Покрутить ручки вида (шум, распад, плотность, пиксель) и сохранить картинку: квадрат или карточку 16:9 для слайдов, на белом или чёрном фоне.

Звук обрабатывается прямо в браузере и никуда не загружается.

## Как запустить у себя

Сборка не нужна. Достаточно открыть `index.html` в браузере. Для записи с микрофона страницу лучше открывать по https (например, через GitHub Pages) или с `localhost`.

## Устройство

- `index.html` — разметка
- `style.css` — оформление: чёрное и белое, Georgia, белая страница
- `app.js` — анализ звука (своя FFT), генератор биомеханических растений, голос на Web Audio, ручки
- `archive/` — первая версия «Звук в рисунок»
